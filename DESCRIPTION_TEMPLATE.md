# Description template (bottom of every video)

Copy this block to the end of each video description. Add the sources for that video above it.

```

The Detour Lab checks the things you think you know, using real sources and simple math.

■ Corrections
If you find a mistake, tell us in the comments. We will check it and correct it.

```

## Short video extra line

For Shorts, add this above the template:

```
A longer version with all the sources: [VIDEO URL]
```

## Rules for the description

- List each source with the name of the organization and a link.
- If a source is a summary written by someone else, say so.
- If the original text was not checked, say "We did not check the original document."
- If an image or video is AI-generated, say so. Do not present it as a real photo, document, or footage.
- Put the date on news topics: "Information as of 2026-11-24."
