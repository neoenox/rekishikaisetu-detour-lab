# Plain-English style guide

Write for a smart reader who is learning English. Keep the sentence short, but keep the idea complete.

## Writing rules

1. Use short sentences. About 12–18 words is a good target. One idea per sentence.
2. Use everyday words. Say "show" instead of "demonstrate", "use" instead of "utilize".
3. Explain a technical word the first time you use it. Example: "declination — the angle between map north and compass north."
4. Put the number first, then the source. Example: "About 32 times. That is what the Japan Meteorological Agency says."
5. Do not say "experts say". Name the organization.
6. If two explanations exist, give both. Say which one the source supports.
7. If the original document was not checked, say so.
8. Do not add a moral at the end. End with the question that is still open.
9. No "In conclusion", "Let's dive in", "If you liked this video", or "Don't forget to subscribe".
10. The last line may return to the first line. That is a shape, not a summary. Example: "That is another detour. This time, we took it on purpose."

## Words to avoid

| Avoid | Use instead |
| --- | --- |
| utilize | use |
| demonstrate | show |
| approximately (for simple numbers) | about |
| various | several / different |
| it is important to note | (remove it) |
| fascinating / mind-blowing | (remove it) |
| studies show | "A study by [name] found..." |

## Numbers and dates

- Write dates as 2026-11-24, not 11/24.
- For news, add "Information as of 2026-11-24."
- Write "about 32 times", not "roughly 32x".
- If you calculate a number yourself, say "Our calculation" or "Self-calculated".
